# Demo function for template preview only

Exists solely so the template package has documented reference content
to render in its own preview site. Not part of the public theming API.

## Usage

``` r
tk_demo(x)
```

## Arguments

- x:

  A numeric vector.

## Value

The mean of `x`.

## Examples

``` r
tk_demo(1:10)
#> [1] 5.5
```
