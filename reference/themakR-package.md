# themakR: 'pkgdown' Theme for the CTTIR Package Suite

Provides a custom 'pkgdown' template that gives the Computational Trauma
and Tissue Injury Research (CTTIR) family of R packages a shared visual
identity: a single blue accent, monospace code styling, light and dark
colour modes, and consistent navbar, hex, and footer treatment. It is
not intended for general use outside the CTTIR suite.
