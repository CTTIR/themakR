# Changelog

## themakR 0.2.0

- Prepare the package for CRAN: the maintainer address is now
  <raban.heller@uni-ulm.de>, `Language` is declared, the `Description`
  is written in full sentences, `inst/CITATION` takes the version from
  the installed package, and `cran-comments.md` is added.
- Use neutral wording in the README introduction and drop the CRAN
  status and download badges from the README source and the vignettes.

## themakR 0.1.0

- Standardize the named v5 package logo across README, documentation
  pages and available application headers, with matching light and dark
  artwork.

- Initial release: shared pkgdown template for the CTTIR suite.

- Hugo Coder palette (light `#fafafa`, dark `#212121`, blue link accent)
  with pkgdown’s native light/dark/auto switch.

- rotemplate-style navbar (hex + brand far left, Search · Reference ·
  Articles · Changelog · GitHub · toggle on the right) and home sidebar
  (Links · License · Community · Citation · Developers · R-universe).

- Inter body/heading font, JetBrains Mono code font.

- Shared suite footer with per-package `part_of` wording override.

- Per-package accent override via `template.bslib.primary`.
